# DX Dedicatoria

Una experiencia web 3D romántica y cósmica creada con Three.js, GSAP y Vite.

Esta app combina:
- un viaje interactivo por el universo
- un corazón como símbolo central
- recuerdos visuales con fotos personales
- mensajes y recordatorios románticos
- una estética visual inspirada en el amor, la astronomía y la nostalgia

## ✨ Características

- Escena 3D inmersiva y móvil-friendly
- Galaxia y TON 618 como elementos visuales principales
- Corazón de partículas
- 16 recuerdos con imágenes y textos personalizados
- Mensajes orbitantes alrededor del escenario
- Música de fondo con inicio diferido
- Modal de recuerdos con diseño elegante

## 🛠️ Tecnologías

- Vite
- Three.js
- GSAP
- HTML5
- CSS3
- JavaScript

## ▶️ Instalación

1. Clona el repositorio:
   ```bash
   git clone <tu-repo-url>
   cd memory-space
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el proyecto en modo desarrollo:
   ```bash
   npm run dev
   ```

## 🧱 Build para producción

```bash
npm run build
```

Los archivos listos para desplegar quedarán en la carpeta `dist/`.
